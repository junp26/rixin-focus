# 日日新 · 专注时钟

一个足够简单的专注时钟。无需注册、无需登录，打开就能用。

**在线使用：<https://junp26.github.io/rixin-focus/>**

> 苟日新，日日新，又日新。

## 打开方式

**手机使用：** 用手机浏览器打开 <https://junp26.github.io/rixin-focus/>，再“添加到主屏幕”，即可像 App 一样全屏使用；首次打开后会缓存资源，断网也能继续计时。

**电脑本地使用：** 双击 **`打开专注时钟.bat`**，或直接双击 `index.html`。

## 怎么用

### 每天的第一件事：打卡

打开专注页，问候语下方有一张「早安打卡」卡片。每天可以打卡一次，点击后页面会播放一段展示动效，把随机抽到的「起身那一刻 / 出门与路上」晨间句呈现出来；同一轮里全部用过之前不会重复（当前 24 句）。打卡卡片会立即从专注页收起，当天不再出现，避免分散注意力；第二天才会重新出现。动效会自动结束，也可以点「开始今天」提前收起。卡片和动效里都会显示连续打卡天数。

打卡记录和专注记录一样，只保存在这台设备的浏览器里。

### 专注前、专注中与暂停时

- **开始前**：计时卡片下方会显示一句「坐下开始 / 积累与复利」的句子；点「换一句」可以换。
- **专注中**：每次开始专注时抽一句「专注中 / 自证与硬气」的句子，整轮保持不变。
- **暂停时**：会换成一句「卡住与想放弃」的句子，轻轻推自己一把。
- 这些句子不会出现在专注完成后的庆祝和归类弹窗里，也不会出现在休息界面；专注结束后的庆祝，仍然留给你自己的庆祝动作。

想增加或修改激励句，直接编辑 `quotes.js` 里对应的数组即可，不需要改 `app.js`。

### 意志力在线：立即开始

首页右上角显示当前专注时长。点它可以选择 15 / 25 / 45 / 60 分钟，也可以输入 **1–180 分钟** 的自定义时长。点 **立即开始** 进入计时，计时中可以暂停、继续或提前结束。

- 提前结束且已专注满 1 分钟：按实际时长记入统计。
- 不足 1 分钟：本次不计入统计。
- 专注结束（完成或提前结束）后，先随机庆祝一下，再弹出归类卡片：选择大类，并写下具体做了什么。
- 点 **立即开始** 后，可以在开始前选择「完成这一轮」或「继续正计时」；预约时也可以单独选择。每次开始都能改，不写在设置里。选择正计时后，到点不会打断，直到你手动结束，加时部分也会计入统计。

### 专注结束后：先庆祝，再记录

每一轮专注结束后，会先随机出现一种庆祝方式（从 59 种里抽，最近十几种不会重复），配一点应景的庆祝动画。做完那个小动作，点 **我庆祝完了**，才会进入归类卡片，选择这次的专注分类、写下具体做了什么。

- **换一个**：如果这一种让你觉得尴尬，就换一种。即时、真实、一种就够。
- **跳过，直接去记录**：不想庆祝时可以跳过，分类和任务记录不受影响。
- 不足 1 分钟的专注不会记录，也不会庆祝；提前结束但已满 1 分钟，仍然会庆祝，卡片上会写「提前结束」。
- 在 **设置 → 专注后庆祝** 可以关闭；旁边的 **试一个** 可以随时预览。

想增加庆祝方式，直接编辑 `celebrations.js` 里的 `RRX_CELEBRATIONS` 数组即可，不需要改 `app.js`。每一条写成 `{ id: 100, group: 'A', text: '……' }`：`group` 用 A–I 中任意一组（决定图标、颜色和提示语），`id` 只用来避免短期重复，填一个没用过的数字即可。

### 现在不想学：预约开始

点 **预约开始**，选择今天 / 明天、开始时间、专注时长（支持 1–180 分钟自定义）和倒计时结束方式。

- **页面开着**：到点会自动开始专注，并尽量发一条桌面通知。
- **页面已经关掉**：下次打开时会提醒你，不会凭空开始。
- 预约只会保留一个，新预约会替换旧的。到点前也可以随时取消。

桌面通知默认关闭。需要的话在右上角 **设置** 里打开；即使浏览器不给通知权限，页面内提醒仍然有效。

### 安装到手机主屏幕

- **Android Chrome / Edge**：在 **设置 → 安装到手机** 点“安装”，或从浏览器菜单选择“安装应用 / 添加到主屏幕”。
- **iPhone Safari**：点浏览器的分享按钮，选择 **“添加到主屏幕”**。
- 添加到主屏幕后会以独立窗口运行，页面资源会缓存，断网也能继续计时；数据和记录仍然只保存在这台手机上。

## 统计

切到顶部 **统计**：

- **总专注时长 / 启动次数 / 完成番茄 / 连续专注天数**
- **每日专注**：
  - 外层饼图统计当天各大类的专注占比。
  - 点击一个分类，进入当天该分类的每一次专注记录，可以看到具体时间段、时长和具体内容。
  - 日期可以直接选择，也可以前后翻页。
- **每周专注**：
  - 柱状图显示所选周一到周日的每日专注时长。
  - 可以选择任意日期定位到那一周，前后翻页；点一根柱子会跳到那一天的每日专注。
- **每月专注**：
  - 月历热力图，颜色越深代表当天投入越多。
  - 可以选择任意月份或前后翻页；点某一天会跳到那一天的每日专注。
- **导出数据**：导出带分类、具体内容与加时时长的 CSV，可用 Excel 打开。

分类可以在 **设置 → 专注分类** 中管理：新增、改名、换颜色或删除。删除分类时，已有记录会归入「未分类」。旧记录没有分类时，可以在每日专注里点进「未分类」，再点具体记录补分类。

统计口径：

- 启动次数 = 实际记录下来的专注次数（满 1 分钟才会记录）。
- 总专注时长 = 所有记录的实际专注时间之和，包含正计时的加时部分。
- 今日分钟 / 热力图 / 分类分布按实际专注时间段计算，跨午夜也不会算错。
- 连续专注 = 最近连续有专注记录的自然日天数（今天还没开始时，会从昨天往前算）。

## 数据说明

数据保存在浏览器的 `localStorage` 中，键名为 `rrx-focus-v1`。

- 清理浏览器缓存 / 网站数据会删除记录，**重要数据请定期导出 CSV 备份**。
- 数据按浏览器和网址隔离：手机与电脑、不同浏览器、桌面网页与“添加到主屏幕”的独立窗口之间不会自动同步。
- 移动本地文件夹、更换域名或浏览器后，原来的记录不会自动跟过来。
- 无痕 / 隐私窗口关闭后数据会丢失。
- 不用联网也不会上传任何内容；线上版本同样只把记录保存在你自己的手机里。
